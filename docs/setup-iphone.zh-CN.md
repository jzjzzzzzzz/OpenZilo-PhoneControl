# iPhone 抖音实机配置与验收

本步骤需要在你自己的 Mac / iPhone 上操作。程序不代你修改系统权限、Apple 账户或手机设置。

## A. 准备可随时退出的配置

1. Mac 与 iPhone 登录同一个 Apple 账户、连接同一个 Wi-Fi，蓝牙开启。
2. iPhone：设置 → 辅助功能 → 辅助功能快捷键，选择“切换控制”。先确认能用三击侧边按钮打开/关闭它；如果快捷键绑定了多项，三击可能先出现选择菜单。
3. iPhone 保持解锁。先不要运行戒指真实输出。
4. Mac：系统设置 → 隐私与安全性 → 辅助功能，允许实际启动命令的 Terminal/Codex/Python。回到终端运行 `./ringphone doctor`，检查 `accessibility_trusted`。

“切换控制”启用时交互方式会改变，先准备好三击侧边按钮退出再开始设置。

## B. 配置 Mac 的一个开关

1. 系统设置 → 辅助功能（部分系统称“无障碍”）→ 切换控制。
2. 查看已有切换。如果 SPACE 已是“选择项目”，优先使用它；不要重复添加同一个按键。
3. 若没有相应切换，添加键盘切换，名称 `Ring Next`，动作先用“选择项目”。等待系统捕获按键时，可手动按空格；也可提前在终端运行以下命令，5 秒内切回捕获界面：

   `./ringphone test-key --key SPACE --delay 5`

4. 开启 Mac 切换控制，在主页面板中选择“设备” → 你的 iPhone → 连接。

如果设备不出现，先检查同一 Apple 账户和 Wi-Fi；按当前系统提示处理手机连接状态。不要通过在手机蓝牙列表里寻找 Mac 来替代这一步，这不是 Mac 伪装蓝牙鼠标的方案。

## C. 把手机接收到的开关配置成上滑

1. 连接成功后，在 iPhone 的“设置 → 辅助功能 → 切换控制”中，检查当前可用的开关及“方案”（Recipes）。不同 iOS 的远程开关名称/呈现方式可能不同。
2. 新建方案 `Ring Douyin Next`；给**实际收到 Mac 输入的那个开关**分配一次自定手势。
3. 录制一条竖直上滑：在屏幕中部横坐标，从约 75% 高度向 25% 高度滑动，约 0.3～0.5 秒，然后保存。避开底部 Home 指示条和右侧点赞按钮。
4. 如果界面把“已存储手势”与方案内“自定手势”分开，直接在该方案的开关动作里录制；不要假设两处保存会自动绑定。
5. 在“启动方案 / Launch Recipe”选择刚创建的方案。打开抖音推荐视频页，激活切换控制/方案。

**兼容性检查点：** 当前 iOS 必须能把来自 Mac 的远程开关分配到这个方案。如果手机不显示可分配的远程开关，或只支持扫描菜单而不能绑定方案，先记录 iOS 版本与该界面；不能把“Mac 已发送空格”当成方案已经生效。

## D. 不接戒指，单独验收后半段

在 Mac 执行：

```bash
./ringphone test-key --key SPACE --delay 5
```

看手机：

- 恰好进入下一条视频：该次链路通过。连续手动测试 10 次，每次只发一次，核对是否一次翻一条。
- 只是手机菜单扫描/选中：连接有效，但没有进入正确的方案，回到 C。
- Mac 文本框出现空格、手机无反应：Mac 切换控制未捕获/转发，回到 B。
- 没有任何响应：检查辅助功能权限、系统切换的“保持时长”等设置。配置 `key_hold_s` 可在 0.02～0.5 秒间调整，需与实际开关配置匹配。
- 多次跳页：检查是否录了多个动作、开关是否设置按住重复；默认发送一次 60 ms 的按下/释放，没有持续连发。

## E. 接戒指验收

```bash
./ringphone pair
./ringphone monitor --duration 30
./ringphone run --dry-run
./ringphone run --enable-output
```

如需导入旧绑定，使用 `./ringphone pair --profile /path/to/profile.json`。同一时刻只运行上述一个长驻命令，先 Ctrl-C 停止上一步。

首选按键双击（`0x0703`），不依赖模式或机器学习模型。先单独验证双击 20 次，再验证一段无操作静置。具体成功率必须按手机实测记录，不以 `posted_keys` 代替。

手势方式用 `--preset gesture`，必须按厂商的长按手势会话流程，详见 [README](../README.zh-CN.md)。普通按键单击只用于切换录音/手势模式，不能当翻页键。

## F. 停止与限制

- 终端 `p` + 回车暂停，`r` + 回车恢复，`q` + 回车或 Ctrl-C 停止程序。
- 手机三击侧边按钮退出切换控制。
- 默认只有“下一条”；第二个独立开关在手机实测通过前不要启用“上一条”。
- Mac 睡眠、手机锁屏、切离抖音、退出远程控制都会影响动作；应用没有读取手机前台 App 或动作执行回执的通道。
